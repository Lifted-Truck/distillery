- **Open questions:**
  1. **Fixture/spec mismatch on the "near recurrence" example.** The brief
     (and the fixture stream's deliberate design) describes alpha#L0006
     ("Prefer deleting code over adding an abstraction.") vs gamma#L0006
     ("prefer  deleting   code over adding an abstraction") as a NEAR
     cross-project recurrence differing by "case/whitespace/trailing-period".
     The pinned `near_signature` algorithm in docs/stream-ops.md (casefold +
     NFC + ASCII-whitespace-collapse + strip only — no punctuation handling)
     does NOT treat a trailing period as removable: the two strings differ by
     more than whitespace/case (gamma's text lacks the period entirely), so
     they hash to different near-signatures (`414ede8e4ea7c097` vs
     `f5591689c5f0039b`) and are correctly NOT grouped by the implementation
     as built. I implemented `near_signature` EXACTLY as pinned (verified via
     a unit test that reproduces the formula inline) rather than silently
     extending it to strip trailing punctuation, since the spec block is
     explicit and doing otherwise would be inventing an undocumented
     normalization rule that then freezes into goldens. I added an explicit
     unit test (`test_fixture_alpha_gamma_L0006_does_not_near_group_due_to_trailing_period`)
     documenting this, plus synthetic inline-fixture tests proving the near
     algorithm DOES group true case/whitespace-only variants across projects
     and does NOT group same-project near-duplicates. The committed golden
     `tests/golden/q-recurrences-near.json` reflects the actual (correct
     per-spec) output: only the alpha/beta L0005 exact-duplicate group.
     Flagging for the lead: either the fixture's L0006 pair should be edited
     to actually only differ by whitespace/case (dropping the trailing period
     difference) to serve as a working near-recurrence example, or
     docs/stream-ops.md's normalization should be extended to strip trailing
     punctuation — both are out of scope for this brief (fixture stream and
     docs/ are out of scope for this implementer) and need a lead decision.
